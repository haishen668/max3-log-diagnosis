# 解密格式

仅在解密失败、出现未知格式或维护解密脚本时读取。

## 容器

- 头长度：44 字节
- 魔数：`05 05 46 08`
- 偏移 8 为版本
- 版本 3：RSA-3072，包装块 384 字节
- 版本 1：RSA-2048，包装块 256 字节
- RSA：PKCS#1 OAEP-SHA1
- RSA 明文：16 字节 IV + 16 字节 AES-128 密钥
- 负载：AES-CBC + PKCS#7
- 明文链路：`diagnose.tar` → `var/exportinfo.tar.gz` → `mobilelog`

脚本使用 PowerShell 7 / .NET 完成 RSA、AES、gzip 和安全 tar 解包，不调用外部程序。tar 读取器校验头部校验和，限制条目数、单文件大小和总展开大小，拒绝绝对路径、`../` 路径穿越和重复输出路径，并把不兼容的文件名字符替换为下划线。

## 验证边界

- 真实格式版本 1：与厂商工具输出 91 个文件，路径、大小和逐文件 SHA-256 全部一致。
- 格式版本 3：RSA-3072 合成容器测试通过，尚无真实设备包交叉验证。

遇到未知版本时保留原始包并报告头部信息，不猜测新格式。不要在报告、聊天或案例库中输出 PEM 密钥。

AES-CBC + PKCS#7 不包含消息认证，解密成功只证明密钥、填充和归档结构可用，不证明包的来源真实性。兼容密钥来自用户提供的厂商工具分析结果；公开再分发前应由发布者确认授权和合规边界。
